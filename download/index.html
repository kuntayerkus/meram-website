Meram for Windows

An .exe installer. It installs for the current user, adds a tray icon, and starts checking for updates on launch.

Every build is published as a GitHub release. If this page cannot reach GitHub, the buttons above still take you to the release list, which is the same file from the same place.

Why Windows warns you about this installer

Because it is not signed. There is no Authenticode code-signing certificate for this project yet, so Windows has no publisher name to show you and SmartScreen says so in the bluntest way it knows how.

You will see “Windows protected your PC” with an unknown publisher. To continue: More info → Run anyway.

Take this seriously rather than as a formality. An unsigned installer is one you are trusting on the strength of where you got it and the TLS connection you got it over — nothing more. Download it from this site or from the GitHub releases page, and from nowhere else. If you are not comfortable with that, waiting for the signed build is the correct decision, and we would rather say so than talk you past it.

The same applies to updates. An installed copy checks GitHub on launch and updates itself in the background — and that channel is unsigned too. It is a deliberate beta trade-off, and closing it is a requirement before anything here gets called stable. You can turn automatic updates off in Settings.

What you need before you start

  • A microphone. Any of them. Meram opens the stream when you hold the key and releases it when you let go.
  • A provider key. Groq (the default) or OpenAI. Onboarding will not let you past the key step until the key you pasted actually verifies — a setup that looks finished but cannot transcribe is worse than one that stops you.

Groq’s Whisper models cost on the order of four cents per hour of audio, billed by Groq. Meram takes no cut, because Meram never sees the request.

The first two minutes

  1. Run the installer, then let the onboarding walk you through the microphone permission and your provider key.
  2. Pick a shortcut, or keep Ctrl+Shift+Space.
  3. Open any application with a text field, hold the shortcut, and say a sentence.
  4. Let go. The text is typed where your cursor was.

If the hold-to-talk hook cannot load — some machines and some security software block low-level keyboard hooks — Meram falls back to tap-to-toggle and tells you, rather than looking like it is listening when it is not.

macOS

Not published yet. macOS runs from the same codebase and can already dictate and type through the Accessibility API, but the build is neither signed nor notarized, which means Gatekeeper will not open it and updates cannot be applied. Shipping an unsigned Mac build would be shipping something that does not work, so it is not here.

Uninstalling

Windows Settings → Apps → Meram → Uninstall. What remains afterwards is the app data folder holding your history database, dictionary and settings — deliberately, so that reinstalling does not throw your vocabulary away. Delete %APPDATA%\Meram and there is nothing left.

Is this safe to install?

It is unsigned, so Windows cannot vouch for it and neither can a certificate. What we can tell you is exactly what it does with your data — and that page names the things that are not private as clearly as the things that are.
